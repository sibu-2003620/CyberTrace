# CyberTrace AI

AI-Based Phishing URL Detection & Cyber Security Platform.

## Current version
This is a complete frontend demo that works locally without a backend.
It includes:
- Responsive cyber-security UI
- URL Analyzer with heuristic risk scoring
- Scan history using LocalStorage
- Dashboard charts using Chart.js CDN
- Cyber Awareness page
- Interactive Cyber Security Quiz
- Login/Register demo using LocalStorage
- Persistent dark/light mode

## Run in VS Code
1. Extract the ZIP.
2. Open the `CyberTrace-AI` folder in VS Code.
3. Open `frontend/index.html`.
4. Right-click -> Open with Live Server.
5. Use the navbar to explore the application.

## Next full-stack upgrade
The folder contains a backend placeholder. The next version can connect the frontend to Python Flask, MySQL and a trained ML model.
